# Ordena

**[Versión en español](README.md)**

**[Open the web application](https://order-management-system-frontend-sigma.vercel.app/)**

Ordena is a web application for managing a business’s orders and day-to-day operations in one place. It lets users create and view orders, manage products, customers, and couriers, and review a summary of sales and order statuses.

This repository contains the Ordena frontend, built with React and Vite. The Settings section is currently under construction.
